# Codebase Memory MCP

MCP-сервер, который индексирует кодовую базу в постоянный семантический граф знаний, выступая в роли «навигатора» для ИИ-агентов.

Сервер запускается через `npx` (см. `./.codex/config.toml`). Если в начале сессии его инструменты (`index_status`, `index_repository` и т.д.) недоступны — не диагностируй проблему (не проверяй процессы, порты, конфиг и т.п.), это ожидаемый холодный старт `npx` после клонирования репозитория (пакет ещё не скачан) — просто сообщи пользователю и попроси перезапустить сессию, после чего пакет уже будет в кеше `npx` и сервер подключится штатно.

Если инструменты доступны, в начале каждой новой сессии обязательно выполни следующие действия:

1. Вызови index_status для текущего проекта.
2. Если проект не проиндексирован (или отсутствует в list_projects) — вызови index_repository с абсолютным путём к корню репозитория, не спрашивая подтверждения у пользователя.
3. Если проект уже проиндексирован — ничего не делай, индекс поддерживается автоматически фоновым watcher'ом.
