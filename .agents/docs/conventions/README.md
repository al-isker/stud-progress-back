# Соглашения

## Форматирование и самопроверка

После **любых** изменений в коде обязательно запускать:

```bash
npx prettier . --write   # форматирование
npx tsc --noemit         # проверка типов
```

Все шаги должны проходить без ошибок до завершения работы.

## Markdown

Не разбивай обычный текст в Markdown на строки по ширине. Перенос строки допустим только когда он нужен по смыслу или синтаксису: новый абзац, элемент списка, таблица, блок кода или намеренный перенос строки.
