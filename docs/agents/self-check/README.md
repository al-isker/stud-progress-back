# Самопроверка

После любых изменений в коде обязательно выполнить следующие проверки.

## Проверка типов

```bash
npx tsc --noEmit
```

Перед завершением работы проверка типов должна проходить без ошибок.

## Проверка форматирования

```bash
npx prettier . --check
```

Если проверка выявила несоответствия в файлах текущей задачи, исправь форматирование только этих файлов, перечислив их пути явно:

```bash
npx prettier "path/to/file-one.ts" "path/to/file-two.ts" --write
```

Затем повторно запусти общую проверку:

```bash
npx prettier . --check
```

и убедись, что в файлах текущей задачи несоответствий нет.

Если общая проверка выявила несоответствия в других файлах, сообщи о них отдельно.
